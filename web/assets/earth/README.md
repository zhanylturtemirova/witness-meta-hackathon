# Earth imagery

The original-resolution textures and the day/night, cloud and atmosphere
treatment are adapted from Master Dev Workshop's `landing-page-example/src/world.ts`.
The workshop's MIT notice is retained in [WORKSHOP-LICENSE](WORKSHOP-LICENSE).

- `earth-day.jpg`: NASA Blue Marble: Next Generation, January 5400×2700 base map.
  https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-map/
- `earth-night.jpg`: NASA Black Marble 2016 global colour map.
  https://science.nasa.gov/earth/earth-observatory/earth-at-night/maps/

Rendering uses the workshop's Three.js version, 0.180.0, bundled locally with
its MIT licence in `web/vendor/three/`. No map key or map service is required.
