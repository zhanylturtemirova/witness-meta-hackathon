[Participant Guide](https://cerebralvalley.ai/e/meta-ai-developer-hackathon/details) требует публичный репозиторий и ясное выделение работы, созданной во время события. Разрешение использовать старые кодовые базы отдельно сформулировано для стартапов; не трактовать это как подтверждение допустимости старого кода для Indie Track.
