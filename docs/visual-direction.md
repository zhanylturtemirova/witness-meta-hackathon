# Witness visual direction

Witness uses a hand-painted storybook style across the application and illustrated memory films. Gouache, pencil texture, warm paper and organic silhouettes share one coherent palette.

## Visual vocabulary

Hand-painted gouache and dry brush on warm paper, coloured-pencil hatching, visible pigment and grain, irregular organic silhouettes, simplified expressive people, layered storybook scenery. Muted ochre, honey, burnt sienna, moss and deep forest green, dusty slate blue, warm cream. Amber practical lighting against quiet dark interiors. Soft atmospheric landscape depth, small domestic details, gently imperfect drawing. Avoid glossy 3D, neon, flat geometric vector scenery and generic purple gradients.

## Application

Warm cream reading and writing surfaces, dark brown text, moss controls, restrained terracotta recording accent. Keep type sharp and accessible: painterly texture belongs in original illustrations and accents, never behind dense text at the expense of contrast. Small illustrated vignettes frame the question and recorder instead of filling the whole screen. Stories resemble readable letters/pages. Keep working forms, focus states, source references, native controls and responsive behaviour.

Connect should belong to this world: a painted atlas / illustrated globe treatment with readable coastlines, consistent geographical projection and real marker coordinates. Warm small location lights and cream quote notes; preserve semantic ranking and candidate-versus-result distinctions. Prepare a preview before replacing the current globe rendering.

## Memory films

Use the same shared visual vocabulary across every scene. Muse Spark plans chronological, source-linked scenes and a shared visual specification. Muse Image creates original illustrations with the approved first frame as reference. Preserve person appearance, clothes, scale, palette and recurring locations. The palette does not imply every memory occurred in autumn: follow the narrator's actual setting.

For Three knocks: childhood rooms, shared wall, adult night interior, phone carrying the familiar signal. For Dad's first message: balcony tomato, father's hands with phone, daughter's distant room, successive plant photographs. Do not invent personal facts or force sadness. Unknown visual details are explicitly imagined or left nonspecific.

Current illustrated export supports image motion and transitions. Camera movement is not character animation. Optional subtle layered effects (steam, firelight, drifting leaves, curtain movement) need separately implemented layers/masks and cannot be promised merely by prompting an image model. Preserve narrator-approved captions and optional original narration.
